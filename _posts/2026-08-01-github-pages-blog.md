---
title: 用 GitHub Pages 搭建博客
tags: [GitHub Pages, Jekyll]
d: 一步步教你在 GitHub Pages 上部署 Jekyll 博客。
---
GitHub Pages 是 GitHub 提供的免费静态网站托管服务，非常适合搭建个人博客。它支持 Jekyll 构建，不需要自己维护服务器，推送代码即可自动发布，配合自定义域名更是体验极佳。

使用 GitHub Pages 搭建博客有几点好处：首先是完全免费，流量和空间对于个人博客来说绰绰有余；其次是天然的版本管理，所有文章都在 Git 仓库中，历史记录一清二楚；最后是自动化部署，推送即上线，省去了手动上传的麻烦。

需要注意的是，GitHub Pages 在安全模式下运行 Jekyll，只允许使用白名单内的插件。所以如果你的站点需要自定义插件，就要考虑其他方案了。
